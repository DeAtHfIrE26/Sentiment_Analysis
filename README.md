## 🌟 Project Overview
<img align="right" width="350" src="https://github.com/user-attachments/assets/5d2d0381-acae-499b-aedd-1de3c25c68f6" alt="KARY Demo" style="border-radius: 10px; box-shadow: 0 5px 15px rgba(0,0,0,0.3);">
KARY is a cutting-edge sentiment analysis chatbot developed as part of an internship project. It leverages advanced AI and ML techniques to understand and respond to user emotions in real-time.

The system combines natural language processing, emotion detection, and contextual understanding to create meaningful human-like interactions. KARY can detect subtle emotional cues in text and speech, allowing it to respond appropriately to the user's emotional state.

Whether you're looking for a virtual assistant that understands your feelings or a research tool for emotional intelligence, KARY provides a sophisticated platform that bridges the gap between human emotions and AI responses.

## 💻 Installation & Setup
<div class="code-container" style="background: linear-gradient(135deg, #FF5F6D11, #00C6FF11); padding: 20px; border-radius: 10px; border: 1px solid #FF5F6D33;">
Clone and Setup

# Clone the repository
  ```bash 
  git clone https://github.com/DeAtHfIrE26/Sentiment_Analysis.git
``` 
# Navigate to the project directory
```bash
cd Sentiment_Analysis
``` 
# Create and activate virtual environment
```bash
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`
```

# Install dependencies
```bash
pip install -r requirements.txt
Configure Environment
```

# Create .env file with your API keys
```bash
echo "OPENAI_API_KEY=your_openai_key_here" > .env
echo "GOOGLE_SPEECH_API_KEY=your_google_key_here" >> .env
```
# Initialize the database
```bash
python init_db.py
Run the Application
```

# Start the backend server
```bash
python app.py
```

# In a new terminal, start the frontend (if using React)
```bash
cd frontend
npm install
npm start
```

# Visit http://localhost:3000 in your browser to interact with KARY
